# 2026-11-25 保管庫（vault）をこのリポジトリに置く

- プロジェクト: [[projects/採用LP-ABテスト]]
- 状態: 採用。リポジトリを private にすることをユーザーが決定（GitHub 上の切り替え待ち）

## 何を決めたか
動画「Obsidianの使い方」（[[sources/2026-11-25_Obsidianで第二の脳を作る]]）の運用を、このリポジトリの `vault/` として導入する。

## 採用した案と理由
- リポジトリ内 `vault/` に置く — クラウドのセッションはコンテナが消えるため、残せる場所はリポジトリ（コミット）しかない。Claude Code がそのまま読み書きでき、Obsidian でも開ける

## 却下・保留した案と理由
- 案: 個人 PC のローカル Obsidian 保管庫に置く — 理由: このクラウドセッションからは書き込めない（PC を接続すれば可能）
- 案: このリポジトリを private にする — **採用**（2026-11-25 ユーザー決定）。保管庫を分けずに済み、生ログもコミットできるようになる
- 案: 非公開の別リポジトリに置く — 却下。リポジトリが 2 つになり管理が増える

## 見直す条件
- private に切り替わったら、CLAUDE.md の手順で生ログのコミットを解禁する
- GitHub Pages で LP プレビューを公開している場合、無料プランでは private リポジトリの Pages が止まる。止まって困るなら別の共有方法を決める
