# 2026-11-25 削除・取り消せない操作はフックで確認必須にする

- プロジェクト: [[projects/採用LP-ABテスト]]
- 状態: 採用

## 何を決めたか
`.claude/hooks/guard_delete.py`（PreToolUse・Bash）で、rm / find -delete / git rm / git clean / git reset --hard / 強制プッシュ / ブランチ強制削除 / 変更の破棄を検出したら、実行前に人間の確認を求める。`/tmp` 配下だけを消す rm は確認なし。

## 採用した案と理由
- 確認を挟む（ask） — 動画の運用「削除しようとする動きは全てフックで制御。確認して OK なものだけ消す」

## 却下した案と理由
- 案: 削除を一律禁止（deny） — 理由: 本当に消したいときに作業が止まる
- 案: 何もしない — 理由: AI にパソコンの操作権限を渡している以上、消える事故は起こりうる

## 見直す条件
- 確認が多すぎて邪魔なら、対象パターンを絞る
