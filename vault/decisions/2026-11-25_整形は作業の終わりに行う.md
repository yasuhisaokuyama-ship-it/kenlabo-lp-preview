# 2026-11-25 日報の整形は「深夜の自動処理」ではなく「作業の終わり」に行う

- プロジェクト: [[projects/採用LP-ABテスト]]
- 状態: 採用

## 何を決めたか
生ログから日報への整形・ノウハウ抽出は、各セッションの作業の終わり（コミット前）に Claude が行う。手順は [[_system/routines]]、ルールは CLAUDE.md。

## 採用した案と理由
- 作業の終わりに整形 — クラウドのコンテナは使い終わると消え、生ログ（コミットしない）も消える。翌深夜まで待つと整形する材料が残っていない

## 却下した案と理由
- 案: 動画と同じく深夜にスケジュール処理で前日分を整形 — 理由: 上記のとおり生ログが残らない。PC 上の Claude Code で運用するなら有効
- 案: 30日以上前のログだけ保存 — 理由: 動画でも「複雑で面倒、最近はログ保持期間が短くなる傾向」とされている

## 見直す条件
- PC 上のローカル保管庫で運用する場合は、深夜のスケジュール処理に切り替える
