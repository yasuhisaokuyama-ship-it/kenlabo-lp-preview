# 2026-11-25 会話の生ログはコミットしない

- プロジェクト: [[projects/採用LP-ABテスト]]
- 状態: 採用

## 何を決めたか
Stop フックが書く生ログ `vault/daily/_raw/` は .gitignore し、整形した日報 `vault/daily/<日付>.md` だけをコミットする。

## 採用した案と理由
- 生ログは除外、整形版のみコミット — リポジトリが public。生ログには依頼文や貼り付けた資料がそのまま入るため

## 却下した案と理由
- 案: 生ログもそのままコミット — 理由: 公開されてしまう
- 案: 生ログを一切取らない — 理由: 「言い忘れたものは残らない」。動画の要点は自動で全部取ること

## 前提・根拠
- 2026-11-25 時点で GitHub 上の公開設定は public

## 見直す条件
- vault を非公開の場所に移したら、生ログもコミット対象にしてよい（.gitignore の 1 行を消す）
