# 採用LP ABテスト（建.LABO×叡智JV）

- 状態: レビュー用プレビュー（公開前）
- リポジトリ: `kenlabo-lp-preview`（public）
- 関連: [[decisions/README]] / 日報 [[daily/2026-11-25]]

## 目的
地方の施工管理・建設エンジニアを東京の現場に採用するため、訴求軸の異なる 2 つの LP を比較する。

## A群・B群
| | A群 `kagoshima.html` | B群 `osaka.html` |
|---|---|---|
| 対象 | 鹿児島県出身者（未経験も歓迎） | 大阪・近畿の施工管理経験者（実務3-5年を想定） |
| 訴求軸 | 「友達と、恋人と、家族と。一緒に上京できる」 | 「移住じゃない、挑戦。東京は新幹線で2時間半」（低コミットメント） |
| 不安への回答 | 5つ（家賃・引越し費用・孤独・家族・帰れない） | 4つ（決断の重さ・経験が通用するか・住まい・戻れるか） |
| 独自セクション | 同伴制度（修正C）、ご家族向け（修正F）、5つの上京支援 | 4つの働き方サポート |
| 給与表記 | 月給25万〜40万円、JSON-LD に年収350万〜600万円 | 面談時に提示（JSON-LD に baseSalary なし） |
| 計測ラベル | `lp_source=kagoshima` / `kagoshima_lp` | `lp_source=osaka` / `osaka_lp` |

共通: 建.LABO WAY（3つの言葉）、5段階の評価のしくみ、キャリアパス、募集要項、30分の無料相談フォーム。
