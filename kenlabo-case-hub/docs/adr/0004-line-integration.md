# ADR-0004 LINE は Webhook + push 返信、あいさつだけ reply

日付: 2026-11-07 ／ 状態: 採用（モックで実装済み、本番チャネルは未接続）

## 文脈
外部顧客（個人オーナー）は LINE 公式アカウントで連絡してくる。社員の返信は数時間後になることが多い。reply API は無料だが replyToken はすぐ失効する。push は月間通数を消費する。受信した画像などは LINE 側で一定期間後に消える。

## 決定
1. 受信は Messaging API の Webhook（`/webhooks/line`）。生ボディで署名検証し、即 200、キューで非同期処理。重複は `webhookEventId` で排除。
2. 社員の返信はアプリから **push**。成功したときだけ記録し、月間通数を数えて 80% で警告。
3. 友だち追加のあいさつ（利用目的・共有先・保持期間・問い合わせ先）は **reply**（無料）で即時に返す。LINE 管理画面側の「あいさつメッセージ」はオフにして二重送信を防ぐ。
4. 画像・ファイルは受信時に取得して保存（本番 Cloud Storage、開発ローカル）。画面では画像だけ表示し、それ以外はダウンロードさせる（HTML などを開かせない）。
5. LINE Official Account Manager のチャット画面での返信はアプリから見えないため、その場合は「対応済み」を記録する運用にする。

## 結果
- 返信がアプリに集まり、未返信の判定（R1 / Y1）が Teams と同じルールで動く。
- push の通数が費用に直結するため、連携状態ページで当月の通数と上限を常に見える化した。
- チャット画面との併用を完全には防げない。運用ルール（返信はアプリから）を鈴木さん・藤本さんと決める必要がある。

## 代替案
- 全部チャット画面で運用し、アプリは受信の可視化だけ: 未返信が解消できず赤が消えない → 不採用。
- LIFF フォームで問い合わせを受ける: アフター依頼の写真送付には有効。P6 以降の拡張として残す。
