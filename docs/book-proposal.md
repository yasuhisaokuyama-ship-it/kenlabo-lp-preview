## 1. 企画の核

**1行**: 「失敗には理由がある。情報不足・思い込み・自信過多の3つだ。AIに仮説検証の前半を回させ、人が後半を握れば、失敗は設計で減らせる。」

**論理**
1. 成功には運の要素が大きく再現しにくい（著者の経験則として書く。統計のように見せない）。失敗には必ず理由があるので、フレームワーク化できる。
2. 失敗の理由は3つに集約される: **情報不足・思い込み・自信過多**（失敗の3病因）。
3. 3病因はいずれも「人が仮説を立て、人が検証する」工程で生まれる。
4. 仮説検証の**前半工程**（仮説の棚卸し、質問設計、候補案の粗い絞り込み、態度や価格受容性の方向確認）はAIが大半を担える。**後半**（実在の顧客での最終検証、個人の購買行動、少数派の反応、新しいカテゴリ）は人間のデータが必須。
5. 前半をAIで回し、人の検証を後半に集中させることで、失敗の単価と回数を下げる。これが設計目標であり、数値は建.LABOの実測が出てから書く。体系化したものが「サクセスホール」。
6. 「7割」を使う場合は「叡智の工程数ベースの経験則」と明示し、「精度7割」と混同させない。

**なぜ今か（2025〜2026年の公的データ、出典はレポート§4）**
- 中小企業の生成AIは「導入したつもり」で止まっている。商工中金 2026年1月調査では「会社で導入せず個人の判断に任せる」が64.9%、課題は「具体的な活用場面が分からない」35.6%。東京商工会議所 2026年7月公表では活用企業83.9%のうち43.2%が無料ツールのみ。IPA「DX動向2026」ではAI導入率42.3%に対し**売上・利益の向上を実感した企業は3.9%**。総務省 令和8年版情報通信白書では業務変革について「組織的な取組はない」が日本27.0%、米国1.4%。
- 「何から始めるか分からない」（Leach社調査 62%）＝情報不足、「個人任せで使っているつもり」＝思い込み、「PoCで成果が出た気になって止まる」＝自信過多。この対応づけは著者の提案であり、研究上の分類ではないと本文で明示する。
- 最も人が採れない業種で最もAIが使われていない。建設業は後継者不在率57.3%で全業種最高、「建築・土木・測量技術者」の有効求人倍率5.58倍（2025年度、職業計1.10倍）、2025年の人手不足倒産427件のうち建設業113件、それでいて建設業のAI導入率は15.9%（中小機構 2026年3月、二次引用）。建.LABOの物語を支える数字になる。
- 中小企業向けAI本は「ツール導入・業務効率化」が中心で、「失敗の法則 × 仮説検証 × AI」という戦略側の切り口はまだ空いている。「失敗」書名の新刊は2025〜26年の主要ランキング上位に見当たらず、潜在需要（『失敗の本質』累計100万部、『失敗の科学』19万部）は厚い。
- 2025年の書籍市場は5,939億円で4年ぶりプラス、返品率31.9%に改善（出版科学研究所、原典未確認）。

## 5. 本書の独自性（4点）

1. **診断フレーム**: 失敗の3病因（情報不足・思い込み・自信過多）。経営者が自社と自分を1枚で診断できる。公的調査の「導入したつもり」の数字と対応づけて示す。
2. **道具**: AIで回す仮説検証ループ。合格ライン70点、課題→解決策→価格→チャネルの4段階、PASS／PIVOT／ESCALATEの判定、反証ペルソナの混入は**叡智のメソッド（検証中の運用知）として書き、研究で裏付けられた閾値とは書かない**。価格受容性はLLMが比較的得意な領域という補足は可。
3. **証拠の両側を引く誠実さ**: 合成ペルソナ研究の支持側（Park 2024: 本人データ接地で人間の自己再現性の85%、属性のみ74%。Hewitt: 処置効果の方向で相関r=0.85）と反証側（Funhouse Mirrors 2026: 接地しても個人レベルr=0.20、分散は93.9%のアウトカムで人間より狭い。Dooskin 2026: 実A/Bテスト330件でLLM判定κ≒0.14）を両方引き、「集団の方向は当たる、個人と絶対値は当たらない」「AIは予選、人間は本選」と言い切る。経営学者である第一著者の信頼を守る。
4. **実録**: 建.LABO 第二創業（2026年8月〜）。内装会社から「空間」の会社へドメインを再定義し、採用LPのA/Bテストや仮説検証をAIで回して、現場が「第二創業をやろう」と動き出すまでの記録。うまくいかなかったことも書く。

加えて、**大学講師（経営学）× 連続起業家（実務）の共著**という構成と、**「執筆にAIを使い、事実と数字は人間が一次資料で検証した」と明示する制作姿勢**が、2026年の出版環境（高文研の絶版・回収、アシェットの刊行中止）では信頼材料になる。『生成AI×経理・会計 実務入門』が「ハルシネーション前提で人の確認を組み込む」設計を売りに発売即重版・1万部に達した例もある（PR TIMES、原典未確認）。

## 13. リスクと対策

| リスク | 対策 |
|---|---|
| 「数字の置き方」が攻撃点になる | 「7割」「3分の1」「85%一致」「精度が上がる」の割合断定を書かない。工程と設計目標で表現し、研究は両側を引く。叡智のルールは「検証中の運用知」と明示 |
| AIツール名が刊行時に古くなる | 本文は原理のみ。ツール名・画面は付録に隔離し、読者特典ページで更新する |
| AI執筆への不信（高文研の回収、2026年9月） | 序章か奥付でAI利用と人間による一次資料検証を明示。企画書にファクトチェック手順を書く |
| 「必ず成功する」と読まれる | 前提条件付きの表現。第5章で「穴を先に見せる」原則を自ら実践する。うまくいかなかった例も第11章に書く |
| 事例企業との関係悪化 | 第12節の許諾を刊行前に書面で取る。匿名化の選択肢を常に残す |
| 補助金・金融の話に見える | 書かないと決める。金融教育講座は「学びの設計」として書き、商品の話はしない |
| 大学規定（第一著者、兼業、大学名の使用） | 執筆・講演は学術の派生として可（大井先生の確認済み）。クレジットと大学名の使用は大学側に事前確認 |
| 奥山の経歴が「ふわっとして見える」 | 連続起業家・叡智代表という事実と、固有名詞なしの数字、本文の実録で担保する |
| 売れない | 1,000部の消化計画を先に持つ（第8節）。売上ではなく「問い合わせ数」「単価」「講演回数」を成果指標にする |
| 買い取り条件が不利 | 著者側から1,000部を提示しない。300〜500部から交渉し、印税方式・買取分印税・在庫引取を契約で確定 |
| 商業出版採択で刊行が2028年にずれる | 1月末の判断に「ずれ込み時の扱い」を含める |
| 「サクセスホール」の名称 | 商標の出願を検討（ビジネスモデル特許は進歩性の面で難しいという見立て）。書名にはせず章タイトルで使う |

## 付録1. 大井先生にまとめていただきたい論点（A4一枚で可）

1. 経営学の立場から見た「失敗」の捉え方。『失敗の本質』以降、何が語られ、何が語られていないか。
2. AIによる仮説検証を、既存の経営理論（リーン、ブルー・オーシャン、ストーリー戦略など）の地図のどこに置くか。
3. 講義で学生に見える変化。AIを使う学生と使わない学生で、発表や思考に差が出ているか。
4. スポーツビジネスの知見から本書に入れたい視点（例: 勝敗の非対称性、運と実力の分離）。
5. ご自身が書きたい章、あるいは加筆したい章。
6. 出版社・編集者の知り合い、過去の執筆依頼で接点のあった媒体。
